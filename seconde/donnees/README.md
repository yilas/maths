# Population des cantons au 1er janvier 2025

Source : STATEC, *La démographie luxembourgeoise en chiffres, édition 2025*,
tableau 2, page 11 (11e page du PDF).
[Publication originale](https://statistiques.public.lu/dam-assets/catalogue-publications/en-chiffres/2025/population-chiffres-2025.pdf).
Source statistique indiquée : STATEC / RNPP. Consultation : 18 octobre 2026.

Transcription des deux colonnes « Femmes » et « Hommes » pour les douze cantons.
Les catégories et intitulés suivent la source. Le sous-total « dont Ville de
Luxembourg » est volontairement exclu : il est déjà inclus dans le canton et
l'ajouter compterait deux fois ses habitants. Les totaux ne sont pas une treizième
ligne ; ils sont recalculés.

- Femmes : 339 161.
- Hommes : 342 812.
- Ensemble : 681 973.
- Esch-sur-Alzette : 195 091 ; autres cantons : 486 882.

Une ligne représente un agrégat cantonal, pas une personne. Les comparaisons
portent sur la population à cette date, pas sur une estimation actuelle.
Le tableau Esch / autres du cours est une transformation par regroupement.
Les proportions sont calculées à partir des effectifs exacts, puis arrondies.

Le script `python3 seconde/python/verifier.py` vérifie les sommes et les marges.
