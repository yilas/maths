# Programme de seconde générale et technologique

Programme du BO du 2 avril 2026, applicable à partir de la rentrée 2026.
[Texte officiel](https://www.education.gouv.fr/bo/2026/Hebdo14/MENE2602914A).

Le [guide](https://github.com/yilas/maths/releases/latest/download/seconde-guide.pdf) donne la table de couverture des
64 rubriques retenues, les fondements admis, la progression et les automatismes.
Les chapitres 1 et 23 sont des références à mobiliser toute l'année.
L'ordre ci-dessous facilite la consultation ; l'apprentissage alterne les thèmes.

Le [cours](https://github.com/yilas/maths/releases/latest/download/seconde-cours.pdf) est accompagné de
[144 exercices et six synthèses](https://github.com/yilas/maths/releases/latest/download/seconde-exercices.pdf),
de leurs [corrigés expliqués](https://github.com/yilas/maths/releases/latest/download/seconde-corriges.pdf) et de
[programmes Python exécutables](python/README.md).

Les démonstrations exemplaires du programme sont toutes rédigées.
Les compléments sont signalés et le chapitre 24 est entièrement facultatif.
Ils préparent une progression vers la spécialité de première, la terminale
et les mathématiques universitaires, tout en conservant les attendus de seconde
clairement identifiables.

Pour travailler : chercher les exercices avant de consulter les corrigés,
reconstruire les preuves sans le texte, puis reprendre les points difficiles
quelques jours plus tard. Le guide propose des critères de maîtrise et 60 questions
courtes avec réponses.
